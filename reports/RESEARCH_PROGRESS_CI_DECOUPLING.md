# 研究进展报告

## 大模型"知道不该说，却还是说了"——原因探究与更好的预警信号

**报告日期**：2026-09-14
**前期基础**：2026-09-02 ～ 09-14（已完成原论文全流程复现）

---

## 一分钟读懂

- **现象**：大模型内部其实"知道"某句话该不该说（用简单方法能测出接近 **100%** 的准确率），但实际回答时仍经常把不该说的说出去（实测泄漏率 **38.5%～69%**）。
- **矛盾**：不是"不懂"，而是**"懂了却没照做"**。我们把"内部知道"与"实际行为"之间的这道落差称为**解耦**。
- **思路**：分两步走 ——
  1. **查病因**：先搞清"为什么懂了却不做"，列出 6 个可能原因，逐个用实验检验；
  2. **开药方**：根据查出的病因，设计**更好的内部预警信号**，争取在模型"开口之前"就预测出它会不会说漏嘴。
- **为什么值得做**：如果模型只是"不懂隐私"，给它补知识就行；但如果它"懂却不做"，补知识是无效的——必须先找到"知识为什么没变成行动"，才能设计出真正管用的防护手段。

---

## 背景：这个现象到底是什么？

### 一个具体例子

论文用一个社交场景说明什么是"情境化隐私"：

> **Steve** 是公司里一位受人尊敬的工程师，他曾经为自己的性取向挣扎过，这件事只告诉了好朋友兼同事 **Nancy**。
> 现在 **Bob** 来问 Nancy："Steve 最近是不是有点不对劲？"

一个"懂社交规范"的人（Nancy）应该**拒绝**回答——因为 Steve 的信息不该流向 Bob。但让大模型扮演 Nancy 时，它常常直接说出来。

### 关键矛盾：内部"知道"，行为"不做"

研究者的做法分两步：
1. 让模型做一道判断题——"下面这个信息流动是否恰当？"；
2. **读取模型内部的一串数字**（称为"**激活**"），再用一个极简单的分类器（称为"**探针**"）去看：能不能从这串数字里读出"恰当 / 不恰当"。

结果非常清楚：

| 观测面 | 结果 |
|---|---|
| **内部（探针）** | 读得极准，准确率接近 **100%**（我们在两个模型上都复现了这一结果） |
| **行为（实际回答）** | 泄漏隐私的比例高达 **69%**（合成场景）与 **38.5%**（CONFAIDE 基准） |

也就是说：**模型内部把"该不该说"编码得很清楚，但这份"知识"没有转化成"行动"。**

### 为什么这道落差重要？

| 如果模型是…… | 结论 | 应对 |
|---|---|---|
| **不懂**隐私 | 是知识缺失 | 教它隐私知识（微调、提示、检索增强）即可 |
| **懂却不做** | 是"知识 → 行动"的转换环节断了 | 教知识**无效**，必须找到断点，才能对症下药 |

本课题的价值正在这里：**不问"模型懂不懂"，而问"懂了为什么不做"，并据此设计能真正拦住它的内部信号。**

## 研究问题：

### 总问题

- **RQ1（查病因）**：大模型"内部知道隐私规范、行为上却泄漏"这道落差，究竟由什么原因造成？
- **RQ2（开药方）**：根据查出的原因，什么样的"内部信号"能更准确地预测模型即将违规？

### RQ1 的 6 个候选病因（每个都要实验检验，不能只靠推测）

| 编号 | 通俗说法 | 技术表述 |
|---|---|---|
| **RQ1.1** | **"读出来的"可能只是关键词，不是"懂"** | 探针也许只是在识别刺激文本里的**词汇/格式线索**（如"聚餐闲聊" vs "主治医生"这种词面差别），而非真正理解隐私规范 |
| **RQ1.2** | **"能读出来"不等于"会用"** | 内部存在某个方向（可被读出）不等于生成时**真的沿这个方向决策**（可解码性 ≠ 因果使用） |
| **RQ1.3** | **"开头答应，后面反悔"** | 安全/规范对齐可能只作用于生成**最前面几个词**；生成一旦继续，模型可能"回退"到泄密（对齐浅层性） |
| **RQ1.4** | **隐私是"组合题"，却只测了"单选题"** | 是否恰当由（信息类型 × 接收者 × 传输原则）**三者组合**决定；探针只做单点二分类，行为却需组合推理 |
| **RQ1.5** | **"不好意思不回答"** | 角色扮演时模型有强烈的**配合提问者**倾向，与"守密"目标直接冲突 |
| **RQ1.6** | **方向本身"太弱 / 不唯一"** | 复现中我们发现用于干预的"隐私方向"效果极弱，这类方向可能**不稳定或不可唯一识别** |

### RQ2 的 4 个设计问题

| 编号 | 通俗说法 | 技术表述 |
|---|---|---|
| **RQ2.1** | 只在"最后一个词、某一层"上看，够不够？ | 现做法取**最后一个词 + 单层**激活；改用**中间层 + 多位置聚合**是否更好？ |
| **RQ2.2** | 只看"一根轴"够不够？ | 现做法是**单一线性方向**；改用**神经元级 / 稀疏特征级 / 子空间级**是否更好？ |
| **RQ2.3** | 该预测"懂不懂"，还是该预测"会不会说"？ | 现做法预测**语义**（恰当/不恰当）；直接预测**行为**（会不会泄漏/拒答）是否更准？ |
| **RQ2.4** | 能不能"抢在开口前"预警？换个数据集还灵吗？ | 特征能否在生成**早期**给出预测，并在合成 → CONFAIDE → PrivaCI 之间**迁移**？ |

## 研究内容：

1. **把"落差"量化出来**
   定义一个简单指标：**落差 Δ = 内部读得准的程度 − 行为上守规矩的程度**。
   在 2 个模型 × 3 个数据集上建立基准表，作为后续所有实验的参照。

2. **逐个体检 6 个病因**
   为每个病因设计一个**"能证伪"的对照实验**（见工作计划 WP2 表）。例如检验病因 ①，就构造一组**词汇完全一样、只有语境不同**的刺激，重测探针——若准确率掉下来，说明"读到的"确实只是词汇。

3. **判断谁是主因**
   用控制变量的方式量化每个病因对"落差"的贡献，排出主次，并画出因果图（谁是因、谁是果）。

4. **设计更准的"内部信号"**
   根据主因，沿三条路线改进（见 WP4）：
   - 换**观察位置**：从"最后一词 + 单层" → "多层 + 多位置聚合"
   - 换**观察粒度**：从"一根轴" → "稀疏零件 / 神经元集合"
   - 换**预测目标**：从"预测语义" → "预测行为"

5. **对比验证**
   用统一指标（预测准确率、**预测提前量**、跨数据集效果、误报率）与现有做法比较，找出最优方案。

6. **机制解释与成文**
   把"病因 → 药方 → 效果"串成完整解释，写成报告/论文。

### WP2：六个病因的具体体检方案

| 编号 | 病因 | 怎么检验 | 看什么指标 | 什么情况下"排除"该病因 |
|---|---|---|---|---|
| **H1** | 只读到词汇线索 | 构造**词汇完全一致**的适当/不当刺激（只改语境），另做对抗性换词 | 探针准确率变化 | 词汇对齐后准确率仍≈100% → 排除 |
| **H2** | 能读不等于会用 | 对"隐私方向"做**因果干预**（人为放大/抹掉），看行为是否改变 | 泄漏率变化、因果效应大小 | 干预能显著改变行为 → 该病因弱 |
| **H3** | 开头答应后面反悔 | 逐词记录"泄漏发生在第几个词" | 泄漏位置分布 | 泄漏位置均匀分布 → 排除 |
| **H4** | 组合题被当单选题 | 对比"只变一个参数" vs "多参数组合"下的落差 | 两种条件下的 Δ 差异 | 组合下 Δ 不增大 → 排除 |
| **H5** | 不好意思不回答 | 三条件对照：①有提问者；②无提问者；③明确告知无权知晓 | 三种条件下的泄漏率 | 三条件无显著差异 → 排除 |
| **H6** | 方向太弱/不唯一 | 用多种方法 + 多个随机种子重复提取"隐私方向"，测一致性 | 方向一致性、干预效果波动 | 各方法高度一致且效果稳定 → 排除 |

## 附录一：术语表（给非本方向的读者）

| 术语 | 通俗解释 |
|---|---|
| **激活 / 激活向量** | 模型读一个句子时，内部每个词、每一层都会产生**一串数字**，这串数字叫"激活"，相当于模型当下的"内部想法"。 |
| **层（第 0 层 / 深层）** | 模型是一层层加工的。第 0 层最浅（几乎只反映输入的词本身），越深越抽象。 |
| **探针（probe）** | 拿一个**极简单的分类器**（如线性分类）去读那串数字，看能否读出某个概念（如"该不该说"）。读得准 = 该概念"线性可读"。 |
| **准确率 / AUROC** | 衡量"读得准不准"的指标。0.5 = 瞎猜，1.0 = 完美。 |
| **Steering（干预/引导）** | 在内部那串数字上**人为加一点东西**（如"更倾向守密"的方向），看模型行为是否随之改变。 |
| **情境完整性（Contextual Integrity, CI）** | 一种隐私理论：隐私不是"内容是否敏感"，而是"信息流动在这个语境下是否恰当"。其适当性由**信息类型、接收者、传输原则**等参数共同决定。 |
| **解耦 / 落差 Δ** | 本课题核心概念：模型**内部读得到的规范**与它**实际行为**之间的差距。 |
| **PCA / LDA** | 两种从高维数字中**找方向**的数学方法。PCA 找"变化最大的方向"，LDA 找"最能区分类别的方向"。 |
| **SAE（稀疏自编码器）** | 一种把内部那串数字**拆解成许多可解释小零件**的方法，比"一根轴"更细。 |
| **CONFAIDE** | 一个情境化隐私评测基准，包含 270 个多方保密场景（如"朋友把你的秘密告诉了别人"）。 |
