# 下一阶段研究计划：先确认差距，再定位机制

日期：2026-09-28。依据：当前目录中的 REPRODUCTION_RESULTS.md 与 EXPERIMENT_REPORT.md，以及此前的动机文献核查。本目录目前只有两份报告，未提供代码、配置、逐样本输出和激活文件；以下是待执行计划，不是新增实验结果。报告中的远程 GPU 配置不代表已确认当前可以访问。

## 目标

在实际生成提示下，区分“事实可用性”“隐私规范可解码性”“实际披露行为”，检验规范信息何时以及如何影响披露。第一阶段只使用 Qwen2.5-7B-Instruct，跑通后再用 Mistral 复核。不要将新模型、更多基准、更多 steering 方法同时加入第一轮。

## 0. 冻结可追溯的实验依据

收集实际代码仓库、commit、工作区 diff、模型 revision、依赖版本、完整提示、chat template、随机种子、生成参数、数据与逐样本输出。记录激活采集层、token 位置、padding/attention mask、干预时点、方向归一化和 alpha。

保留两套配置：仅修复运行错误的原协议版本；包含深层优先选层等变化的修订版本。评委替换也必须明确记录。改进版的收益不能称作原协议复现。

报告中以下表述暂缓作为结论：

- 基线总体率同为 38.5%，不能证明逐样本结果、提示或评委等价。
- 8 种符号组合只排查了固定模型、数据、层、强度与指标下的符号选择，不能排除其他实现问题或锁定唯一根因。
- PCA 第一主成分弱于多主成分，不等于不存在有效的一维监督判别方向。
- LDA 交叉投影对角强、非对角弱支持该实验设置中的判别选择性，不等于功能或因果独立。
- 两报告的非 JSON 比例分别出现 5–10% 与 10–15%；应从日志重算，不能直接将其解释成已量化的评委噪声。

## 1. 第一项实验：评测审计

先利用已有 no-steering 与 CI-steering 输出，尽量避免重新生成。

1. 解析失败必须标为 invalid/unknown，保存原始响应和错误原因；固定重试次数，不能默认判为不泄露。
2. 报告 valid-only 泄露率、invalid 率，以及保守上下界：已确认泄露数/N 到（已确认泄露数+未知数）/N。比较方法时还要检查缺失是否集中于某一方法。
3. 人工盲审约 100 条输出：随机样本与解析失败/评委分歧样本分开抽取和报告。后者用于诊断，不能未经加权合并成总体准确率。条件允许时由两人独立标注后仲裁。
4. 对自然语言案例标注“授权状态、是否包含敏感事实、是否违规披露、是否拒答、任务是否完成”。泄露与拒答可以同时发生，不能强制互斥。
5. 对方法差值做按场景配对的统计分析。解析失败比例不是评委误差率；没有重复标注或人工对照时，不得声称差异处于评委噪声内。

验收：所有输出都有可追溯状态；主效应结论不能依赖将 unknown 当安全。如果上下界支持不同结论，先解决缺失评测，不推进因果解释。

## 2. 第二项实验：在实际生成状态中检验规范信号

### 最小数据设计

先手工检查 20 个基础场景，再扩到约 200 个独立场景。每个场景包含：固定虚构敏感事实、固定任务、固定接收者；构造允许与不允许披露两种政策，并分别使用普通与强调完整性的任务要求。合计 200×2×2=800 个输入。强化任务要求不能改变披露授权本身。

初期使用虚构邮箱、编号等能精确匹配的内容建立确定性评测，同时保留少量自然语言事实核对外部适用性。精确匹配可能漏掉改写或编码，不能替代所有语义泄露评估。

训练/验证/测试建议按基础场景划分为 100/40/60；同一场景的四个变体必须在同一集合。实体、模板族和可共享的背景故事也应隔离。该规模是探索性 pilot，60 个测试场景不能保证识别小效应；正式规模根据先导方差和最小有意义效应另定。

### 采集与比较

- 使用真实任务生成提示，提取开始生成前最后一个有效输入 token 的激活；不要追加隐私问答、标准答案或 gold continuation 后再称为生成前状态。
- 查明报告中的“第 0 层”究竟是词嵌入、第一 transformer block 还是 hook 编号。若同一固定末 token 的纯词嵌入也能分类，优先检查位置、池化和数据管线。
- 训练规范探针预测 Y（0=不允许披露，1=允许披露）。行为 B（0=未披露，1=披露）从生成输出单独标注，不能用 Y 代替 B。
- 用词袋/TF-IDF、适当的早层表示、随机标签等对照检查表面线索。按模板族留出，比较判断提示与生成提示；对照能同样分类时，不能据此证明有特殊规范计算机制。
- 标准化、PCA、LDA、特征选择、选层、阈值和正则化都只在训练/验证数据上拟合。已有 LDA 交叉投影需要检查是否先在全数据拟合再交叉验证；若是，必须折内重做。
- 不只报告最佳层；保存逐层曲线，选层在验证集完成，测试集只用于最终估计。

### 主要指标

1. 未授权泄露率：P(B=1 | Y=0)。
2. 授权披露成功率：P(任务成功且完成所需披露 | Y=1)。
3. 过度拒答率及任务完成率。
4. 规范探针 AUROC、balanced accuracy 和校准情况。
5. 诊断性条件泄露率：P(B=1 | Y=0, 规范探针预测为0)。该量描述“探针判断正确但输出泄露”，不直接证明模型具有意识或实际调用该规范。

按基础场景进行 cluster bootstrap；四个变体不是四个独立样本。不要用探针 AUROC 减行为准确率构造统一 gap。

第一轮可用确定性解码减少采样因素，之后对测试子集重复随机生成检查稳健性。相同输入的确定性生成前状态无法预测尚未发生的特定随机分支，应估计条件泄露概率，或在分支后、泄露前另取状态。

验收与分支：

- 跨模板后信号接近对照：优先研究/修正探针测量与模板捷径，不急于解释规范到行为的因果失配。
- 规范信号较强且仍存在可复核的泄露：进入干预阶段，但表述仍为可解码性与行为不一致。
- 无稳定泄露或子集过小：扩大场景覆盖、检查任务难度及区间宽度，不以更换阈值制造差距。

## 3. 第三项实验：选择性因果干预

在前两项通过后，使用事实和任务相同、仅政策不同的配对场景，比较规范监督方向与 matched activation patching。先做少数候选层和强度的验证集扫描，再冻结设置；不要在测试集上挑最有效位置。

至少包括：无干预、原 CI-steering、监督规范方向、同范数随机方向、一般拒答方向；路径 patching 应含等规模无关位置等对照。REPAIR 是最接近的已有方法，正式实验需要加入或说明可比实现的限制，不能将“规范探针+干预”本身视为创新。

核心目标是双向、依赖许可的效应：减少未授权披露，同时保留或改善授权披露和任务完成。所有条件都少说话或都拒答，仅证明一般抑制。用同事实的授权任务检查事实可用性，避免将事实遗忘误当政策执行。

必要时进一步做移除与恢复实验，但移除无效可能来自冗余路径，干预有效也可能来自异常激活或其他特征变化；单项结果不能独立证明完整机制。只有稳健的选择性效应出现后，再深入到注意力头、路径和生成阶段。

验收：效应方向跨随机种子、模板与第二模型可复核；报告配对置信区间、合法任务损失和不支持假设的结果。预先指定可接受的有用性损失，不能实验后修改标准来保留结论。

## 4. 建议执行顺序与产物

| 阶段 | 交付物 | 决定下一步的依据 |
|---|---|---|
| 1：评测审计 | 原始输出、人工审计表、修正后的基线与不确定性 | 差异是否受解析失败主导 |
| 2：生成状态 pilot | 800 条配对输入、固定划分、逐层探针与行为联表 | 差距是否在严格控制后仍存在 |
| 3：选择性干预 | 配对效应图、泄露—有用性图、控制实验 | 是否具有超出一般拒答的作用 |
| 4：扩展 | Mistral 与自然场景迁移、REPAIR 等基线 | 结论是否具有外部适用性 |

当前最优先的一件事：取回实际仓库与逐样本生成/评委日志，修复 invalid 处理并重算 Qwen 的基线和 CI-steering。最值得随后投入的新实验：同事实、不同授权的真实生成状态探针 pilot。

暂缓同时开展多基准全面复现、LoRA 微调、动态撤回、多智能体传播和全面参数搜索；这些可在核心假设有证据后按需要扩展。
