# 第一部分：总体情况

## 一、研究问题

| 编号 | 研究问题 |
|---|---|
| **RQ1** | 大语言模型是否在**内部激活空间**中编码了情境化隐私规范（Contextual Integrity, CI）？以何种几何结构编码？ |
| **RQ2** | 若内部编码确实存在，为何模型**行为上仍然泄漏隐私**？这种"编码 ↔ 行为"解耦（隐私意识差距）的成因是什么？ |
| **RQ3** | 能否利用该内部结构（沿 CI 三参数分解的子空间）做**推理时干预（steering）**，从而减少隐私泄漏？ |
| **RQ4** | 是否存在比论文所用线性探针**更有效**的方法，用于**预测** LLM 破坏 CI 的行为？ |

## 二、研究内容

1. **方法复现**：完整复现论文五阶段流水线——刺激生成 → 激活提取 → 表征探针 → CI 参数分解 → steering 评测。
2. **结论检验**：逐条检验论文三大发现（Finding 1 多维线性编码 / Finding 2 隐私意识差距 / Finding 3 CI 子空间独立性）在独立模型与独立评委下是否成立。
3. **分歧归因**：对复现中与论文不一致的结果，定位到官方代码的具体实现缺陷并给出证据。
4. **文献调研**：针对 Finding 2，调研"解耦成因"与"更优预测方法"两条文献线，形成后续可执行的验证方案。
5. **产物沉淀**：结果数据、验证脚本、实验报告、文献综述。

# 第四部分：当前结论与风险

## 结论

1. **论文的表征层结论（Finding 1 & 3）稳健成立**：两个独立模型上，"隐私线性可编码、多维非单方向、三个 CI 参数占据功能独立子空间"均被复现；其中 Finding 3 用**论文原始方法（LDA 交叉投影）**验证，结果与 Figure 7 完全一致。
2. **论文的行为层核心收益未能复现**：CI-parametric steering 在合成数据仅降 ~4 个百分点、在 CONFAIDE 上不降反升（38.5%→41.9%，论文为 15.2%）。
3. **分歧根因已定位**：官方代码用"5 分类 PCA 第一主成分"作为 steering 方向，方向**符号正确但强度太弱**；且官方代码**缺失论文 Appendix G 的 LDA 交叉投影**、层选择在合成数据上退化。
4. **CONFAIDE 基线 38.5% 与论文逐字一致**，说明评测流水线正确，分歧集中在**方向提取方法**。

## 风险与限制

| 风险 | 影响 | 缓解 |
|---|---|---|
| Llama-3.1 / Llama-2 门控未授权 | 论文 4 个模型中 2 个缺失 | 已用 Qwen2.5 + Mistral 覆盖两种架构；可申请 Meta 授权补全 |
| DeepSeek 评委 ~10–15% 非 JSON | 泄漏率轻微低估 | 已加非 JSON 重试与增强解析；后续可换回 GPT-4o-mini 对照 |
| 网络受限（PyPI/HF AWS CDN） | 模型下载耗时数小时 | 已改用清华 PyPI + hf-mirror |
| 合成数据词汇可分性过强 | 探针在所有层 acc=1.0，层选择退化 | 已修正层选择；建议后续做**词汇平衡刺激**验证 |
